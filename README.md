 🛒 Amazon Clone (Mini Project) using HTML,CSS
 
A mini project replicating the Amazon homepage using HTML and CSS, focused on responsive design, layout structuring, and modern UI development.

## 🚀 Features

* Amazon-like homepage UI
* Responsive layout (basic)
* Navigation bar with search section
* Product sections and banners
* Clean and structured design


## 🛠️ Tech Stack

* HTML5* - Structure of the page
* CSS3* - For styling and layout
